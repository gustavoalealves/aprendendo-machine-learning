## Projetos

### 02 - Classificação de Diabetes com K-Nearest Neighbors (KNN)

Projeto introdutório de classificação utilizando o algoritmo K-Nearest Neighbors (KNN) para prever diagnósticos de diabetes com base em duas características:

- **Glicose:** nível de glicose.
- **IMC:** Índice de Massa Corporal.

**Tecnologias utilizadas:**
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

**Configuração do modelo:**
- Algoritmo: K-Nearest Neighbors (KNN)
- Número de vizinhos: 5
- Dados de treinamento: 70%
- Dados de teste: 30%

**Resultado:**

O modelo alcançou uma acurácia de **73,33%** sobre os dados de teste.

Este projeto possui finalidade exclusivamente educacional, com o objetivo de explorar conceitos básicos de Machine Learning. O modelo não deve ser utilizado para diagnósticos médicos.
